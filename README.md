# React Shopping Cart Application

A modern shopping cart frontend built with React, Vite, and Lucide Icons.

## Features Implemented
- 🛒 **Shopping Cart Sidebar**: Real-time quantity updates with single & multi-step (+5, -5) controls.
- 🔔 **Toast Notifications**: Interactive toast alerts when items are added to cart or checkout completes.
- 💬 **Confirmation Dialog Window**: Confirmation modals on checkout and item removal.
- 🔍 **Product Search & Filter**: Real-time name search and category filtering pills.
- 📊 **Unit Tests**: Full test suite built with Vitest and React Testing Library.

## Getting Started

```bash
npm install
npm run dev
```

## Running Tests

```bash
npx vitest run
```
